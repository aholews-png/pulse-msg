# Pulse Messenger - Frontend

Безопасный мессенджер с end-to-end шифрованием

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev

# Сборка для продакшена
npm run build
```

## Разработка

Приложение использует:
- **React 18** - UI библиотека
- **Vite** - сборщик модулей
- **Zustand** - управление состоянием
- **React Router** - маршрутизация
- **Socket.io** - реал-тайм коммуникация

## Структура папок

```
src/
├── components/   # Компоненты интерфейса
├── pages/        # Страницы приложения
├── store/        # Zustand хранилища состояния
├── App.jsx       # Главный компонент
└── main.jsx      # Точка входа
```

## Доступные скрипты

- `npm run dev` - Запуск в режиме разработки на http://localhost:5173
- `npm run build` - Сборка для продакшена
- `npm run preview` - Просмотр сборки
- `npm run lint` - Проверка кода
